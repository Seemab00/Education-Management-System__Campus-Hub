# Campus Hub - Education Management System

## 📌 About

**Campus Hub** is an Education Management System (EMS) developed as a Software Engineering project. It provides educational institutions with an all-in-one platform to manage student records, track attendance, handle fee payments, and streamline administrative tasks.

---

## ✨ Features

### Admin
- Course allocation for students & teachers
- Fee management & payment tracking
- Student record management (CRUD)

### Teacher
- Post announcements & reminders
- Course management (materials, assignments, grading)
- View student data (records, attendance)

### Student
- Personal record management
- View attendance & fee status
- Course registration & schedule viewing

---

## 🛠️ Tech Stack

- **Language**: Java
- **Architecture**: Client-Server with MVC Pattern
- **Methodology**: Agile (Scrum)
- **Interface**: Desktop-based GUI
